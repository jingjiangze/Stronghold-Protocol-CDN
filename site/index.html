素材 CDN

把上游（sganggs/Stronghold-Protocol） 的静态素材自动镜像到边缘，并对外提供一套可校验、可引用的接口。内容就是上游 Release 完整包里的同一批文件， 逐文件校验过，不做任何转码。

WHY

这是什么

—

上游把 public/assets/** 放在 .gitignore 里、安装期从第三方仓库下载， 运行期再由部署机自己发。这个 CDN 把「运行期分发」接走：素材只有一份、放在边缘，玩家就近取， 部署机的上行不再被几百 MB 的重复流量占满。

三层来源，一层比一层更抗单点：主源是 R2 自定义域，次源是 Cloudflare Pages（同一棵树、自己的边缘缓存与域名）， 批量通道是把树打成的若干压缩包，走 GitHub Release 并由社区镜像链加速。

与上游的关系：上游 PR #24 已经给素材下载器加了镜像层（SP_ASSET_SOURCE=mirror + SP_GITHUB_PROXY），解决的是安装期从 GitHub 拉取的速度；本站解决的是运行期分发。 两者互补，本站也可以作为上游镜像链里的一个来源。

版本令牌 ?v=… 由内容索引派生（<上游 tag>-<索引 sha256 前 8 位>），字节一变令牌就变

索引 cdn/v1/index.json 全量 { 路径: { size, sha256 } }，用于逐文件校验或做二级镜像

INTEGRATION

接入方式

场景做法
游戏服（本项目 fork） 设环境变量即可，服务端会把三张清单改写成 CDN 绝对地址：
SP_ASSET_CDN=https://weishucdn.jiangjiangze.icu/
纯静态 / 网页端 直接取 /data/assets.json，里面已经是绝对地址（带令牌），不要自己拼路径
二级镜像 / 需要校验 读 /cdn/v1/index.json 拿 size + sha256 逐文件比对
上游服务器部署包（未修改） 用一键包 stronghold-cdn-dropin-<tag>.zip：解压到部署目录旁边，运行启动脚本。 它代理未修改的部署并把清单在响应层改写，不改部署包里任何文件，撤销即删文件夹。
下载：Releases
安装期加速 把 CDN 当作上游下载器的一个来源（路径与部署树一致）：
SP_ASSET_SOURCE=mirror SP_GITHUB_PROXY=<CDN>/ npm run assets
