第三镜像：ModelScope 创空间

续《镜像站》与《第二镜像：OpenI》。这篇记第三镜像 ModelScope 创空间——和 OpenI 一样是 「第二份素材树的存放地」，但定位不同：它是我自己 assets-raw 树的一次幂等 git 镜像 （不是别人 fork 的树、也不是运行时源）。它不做玩家运行时源，因为创空间不提供文件直链；它存在的意义是 「树可被 clone / 被 git-mount CDN 挂载」。事实来自 feat/modelscope-mirror 分支的 tools/push-modelscope.mjs 与 Workflow，不是估算（2026-10-11）。

源 assets-raw 推送 幂等 定位 git 镜像
1 结论先行 我自己树的第三份存放，不是运行时源（2026-10-11）

素材树（我的 assets-raw 分支，14,741 文件 / ~2.14 GiB，含 2,476 个皮肤文件）由 tools/push-modelscope.mjs 幂等推送到 ModelScope 创空间 jingjiangze/Stronghold-Protocol 的 cdn 分支，由 mirror-modelscope.yml 每天四次调用。

它不是运行时源：创空间不提供文件直链——/resolve/、/raw/、 /tree/、/api/v1/.../repo/blob/ 对任意路径都返回同一份 ~8.6 KB 的 SPA HTML（实测）。 所以它只能被 clone / 被 git-mount CDN 挂载，浏览器不能直连取字节。 源分支 assets-raw 现已包含 2,476 个皮肤文件（与上游素材同树、字节逐字节一致）， 经 git-mount 层（jsdelivr-assets / ghfast-assets / gitcdn-own→OpenI）以 coverage:full 对外服务； 但本镜像推送默认仍排除 assets/skins/**（--include-skins 开启才带），所以 ModelScope 侧暂不含皮肤。
与另一篇审计区分开：仓库里 docs/audit/modelscope-openi-hanabi-sources.md 审的是 Stardust fork 的 Stardust/arknight-assets（对音频 0% 覆盖、只补皮肤有价值、不接运行时）； 本篇是我自己树的镜像。
MECHANISM

机制（push-modelscope.mjs）

幂等 git push，每日四次 :23

幂等 + 字节保真

  • 先用 git ls-tree -r --name-only assets-raw 枚举源树、算 sha256 指纹，与镜像分支 assets.summary.json 的 treeHash 比对；相同就直接退出、不重传那 ~650 MiB。
  • git archive 直接管道进裸 checkout，不重采样、不转码；.gitattributes（* -text -diff -merge binary）随树带走，任何平台都不能把 PNG/MP3/skel 字节做换行归一化。

实战踩坑（已写入代码注释）

  • 枚举用 ls-tree 不是 tar -tf：tar 还给目录出一行，计数虚高（13,689 vs 真实 12,265），会把谎言写进 manifest。
  • 排除皮肤用 grep 过滤 assets/skins/，不是 ls-tree 的 ':(exclude)' pathspec（被该命令直接拒绝）。
  • tar -x -C 用正斜杠（Git Bash 的 tar 把反斜杠当转义会 "No such file"）。
凭据与签名：推上去的远端 URL 带凭据（MODELSCOPE_URL 环境变量，形如 oauth2:<token>@modelscope.cn/...），脚本绝不打印。 镜像 commit 关 commit.gpgsign（机器快照；本机 gpg-agent 不可用时签名会让 commit 失败）。镜像本就不是溯源源——真正溯源在 R2 原站冻结的 index-*.json 快照。
WHY SEPARATE

为什么单独一条 Workflow

失败语义隔离，不污染 CDN 状态

sync.yml 是 R2/Pages 原站的发布链，有自己的「镜像 → 门禁 → 发布」契约； ModelScope 是不同目的地、不同凭据、不同失败语义——一次 ModelScope 推送失败，绝不能把 CDN 标红。 所以拆成独立 mirror-modelscope.yml、concurrency 分组隔离。

它与 sync.yml（每 6h :17）错开到 :23，互不争抢。与 OpenI 的 openi-mirror.yml（:47）同样错峰。

验收

幂等退出 / 真推送 / 直链返回 SPA 
# 1. 幂等：树未变时一次 cron 只花一次 fetch + 一次 blob 读，输出 "mirror already carries this exact tree"
node tools/push-modelscope.mjs --dry-run        # 本地预览：准备 N 文件、不推送

# 2. 真推送（需要 MODELSCOPE_URL 带凭据，脚本不打印）
MODELSCOPE_URL='oauth2:@https://www.modelscope.cn/studios/jingjiangze/Stronghold-Protocol.git' \
  node tools/push-modelscope.mjs                 # 默认不含皮肤
# 含皮肤（仅上游皮肤集完整时）：追加 --include-skins

# 3. 确认是 git 镜像而非直链源：创空间文件路径返回 SPA HTML，不是字节
